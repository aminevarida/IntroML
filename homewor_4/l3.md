# Отчет по лабораторной работе №4
## Описание отчета 
Данная лабораторная работа посвящена изучению алгоритмов решающих деревьев и ансамблевых методов на их основе. Работа состоит из трех основных частей.
## Используемые библиотеки
- **Pandas** - для обработки и анализа данных
- **NumPy** - для математических операций
- **scikit-learn** - для всего  ML-цикла
## Основные метрики
- Accuracy, Precision, Recall
- F1-score, AUC-ROC

 ## Алгоритмические компоненты
- Расчет критериев разделения - энтропия, индекс Джини
- Поиск оптимальных разбиений - для числовых и категориальных признаков
- Построение дерева - рекурсивное разделение данных
- Ансамблевые методы - бэггинг и случайный лес
## Часть 1
- Исследование математических основ построения решающих деревьев, включая расчет энтропии, критерия Джини и принципов разбиения данных
